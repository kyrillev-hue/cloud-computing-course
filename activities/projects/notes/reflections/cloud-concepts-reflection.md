# Reflection: Cloud Concepts and My Digital Experience

Cloud computing has changed the way people access digital services and applications. Through cloud technology, users can store files, communicate, and use different online platforms without needing to manage physical servers or install everything on their own devices. As a student, I have experienced using cloud-based applications for different tasks and activities.

One cloud service I use is Google Drive. I use it for storing files, saving documents, and accessing school-related materials online. It is classified as Software as a Service (SaaS) because it provides ready-to-use storage and productivity tools through the internet. Google Drive follows a Public Cloud deployment model because it is available to many users and managed by the service provider.

Another cloud application I use is Canva. I use Canva when creating presentations, posters, and other digital designs for school activities. It is a SaaS platform because users can access its design tools online without managing the software infrastructure. It uses a Public Cloud deployment model because its services are available to the public through the internet.

The third cloud service I use is Messenger for communication and sharing information with others. It is considered SaaS because it provides communication features through an online platform. It uses a Public Cloud deployment model since it is accessible to many users worldwide.

I am still new to using Git and GitHub, but I learned that version control is important when developing cloud projects. Git helps track changes in files, while GitHub allows teams to collaborate, review updates, and maintain project versions. These tools help prevent errors and make managing cloud resources more organized. Learning GitHub is an important step for me as I continue developing my skills in cloud computing and IT.

# Cloud Computing Concepts Reflection

Cloud computing has become an important part of my daily life, even before I started studying it in class. Many of the applications and services I use every day rely on cloud technology to store data, provide online services, and allow access from different devices. Learning about cloud computing helped me understand how these applications work behind the scenes.

One cloud service I frequently use is Google Drive. It is an example of Software as a Service (SaaS) because users can store, access, and share files through a web browser without installing or managing servers. It uses a Public Cloud deployment model since Google provides the service to anyone with an internet connection.

Another service I use is Facebook Messenger. It is also classified as SaaS because messaging features are delivered through the internet without requiring users to manage the infrastructure. Messenger operates on a Public Cloud because it is available to millions of users worldwide.

I also regularly use Canva for school activities and presentations. Canva is a SaaS application because it allows users to create designs directly in the browser. Like Google Drive and Messenger, it is deployed on a Public Cloud, making it accessible from anywhere with an internet connection.

Version control is essential in cloud computing because it helps developers manage changes to files, applications, and cloud infrastructure. Without version control, teams could accidentally overwrite each other's work or lose important changes. Git and GitHub provide a reliable way to track every modification, restore previous versions when needed, and allow multiple team members to collaborate efficiently. Using branches and pull requests also helps review changes before they are merged, reducing errors and improving the quality of cloud projects. Overall, GitHub is an important tool for collaboration, organization, and maintaining cloud-based systems.

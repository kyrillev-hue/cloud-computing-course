# Google Cloud Platform Research

## Brief Overview

Google Cloud is Google's cloud computing platform. It provides services for computing, storage, networking, databases, artificial intelligence, and machine learning.

## Global Infrastructure

Google Cloud has infrastructure in different locations around the world. This allows businesses to run applications and services for users in different regions.

## Cloud Management Console

Google Cloud Console is a web-based interface used to create, manage, and monitor Google Cloud resources and services.

## Four Core Services

1. Compute Engine – provides virtual machines.
2. Cloud Storage – provides object storage for files and data.
3. Google Kubernetes Engine – provides managed Kubernetes.
4. Cloud IAM – manages identities and permissions.

## Three Advantages

1. It has strong AI and machine learning capabilities.
2. It provides strong Kubernetes support.
3. It has a large global infrastructure.

## Typical Enterprise Use Cases

Google Cloud can be used for artificial intelligence, data analysis, websites, applications, Kubernetes deployments, and data storage.

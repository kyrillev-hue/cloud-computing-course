# Microsoft Azure Research

## Brief Overview

Microsoft Azure is Microsoft's cloud computing platform. It provides services for computing, storage, networking, databases, security, and artificial intelligence.

## Global Infrastructure

Azure has cloud infrastructure and data centers located in different regions around the world. This helps organizations deploy applications closer to their users.

## Cloud Management Console

The Azure Portal is a web-based interface used to create, manage, and monitor Azure resources and services.

## Four Core Services

1. Azure Virtual Machines – provides virtual machines for running applications.
2. Azure Blob Storage – stores files and other unstructured data.
3. Azure Virtual Network – provides networking for Azure resources.
4. Microsoft Entra ID – manages identities and access.

## Three Advantages

1. It works well with Microsoft products.
2. It provides many cloud services for businesses.
3. It has a global cloud infrastructure.

## Typical Enterprise Use Cases

Azure can be used for business applications, virtual machines, databases, cloud migration, backups, and Microsoft-based environments.
